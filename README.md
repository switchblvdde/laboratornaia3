# Условие
Написать и отладить программу вычисления объема куба и площади его боковой поверхности по заданной длине ребра.
# Алгоритм 
1. Начало программы.
2. Ввод длины ребра куба "a"
3. Вычисление объема куба.
4. Вычисление площади боковой поверхности.
5. Вывод результатов.
6. Конец программы.
